## Структура

```
cooking/
├── README.md              # этот файл: оглавление и правила
└── saharnye-bulochki/     # папка рецепта
    ├── README.md          # сам рецепт
    └── images/            # все картинки к рецепту
        ├── cover.jpg      # обложка, она же первая в рецепте
        ├── step-01.jpg
        └── ...
```

Правила, чтобы сборник не превратился в свалку:

- **Одна папка — один рецепт.** Название латиницей в нижнем регистре через дефис: `saharnye-bulochki`, `bliny-s-farshem`, `glinntveyn-na-2-litra`.
- **Картинки — только в `images/` внутри папки рецепта.** Обложка называется `cover.jpg`, пошаговые — `step-01.jpg`, `step-02.jpg` и так далее.
- **В рецепте есть шапка:** время, выход, температура и краткая характеристика. Ниже — таблица ингредиентов, пошаговое приготовление с картинками, заметки и источник.
- **Источник указываем честно:** ссылка, автор, дата. Если рецепт свой — так и пишем.
- Новая запись добавляется в оглавление в этом файле.

## Как добавить рецепт

1. Создать папку: `mkdir -p <рецепт>/images`.
2. Положить картинки в `images/`.
3. Написать `<рецепт>/README.md` по шаблону выше.
4. Добавить строку в таблицу «Оглавление».
5. Закоммитить и запушить.
